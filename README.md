# Python Basic Projects

Welcome to my repository of Python applications. This repository contains basic projects organized into clean, dedicated folders.

---

## 1. Library Management System
Located in the `library-management/` folder.

A Python-based application designed to manage library operations, including book inventory tracking, student records, and book issuance details.

### Project Structure
* **`library code (1).py`**: The main Python script containing the application logic.
* **`bookstock.csv`**: Database file tracking available books in the library.
* **`entry.csv`**: Logs for daily library entry and exit records.
* **`regive.csv`**: Records of books registered, issued, or returned.
* **`stuinfo.csv`**: Database containing student information and membership details.

---

## 2. Blood Bank Management System
Located in the `blood-bank/` folder.

A Python application designed to streamline blood bank operations, manage blood donor and recipient records, and track blood group inventory availability.

### Project Structure
* **`blood bank code.py`**: The main Python script containing the application logic.
* **`blood bank management`**: Supporting application configuration file.
* **`donor.csv`**: Database storing donor details like names, contact info, and blood types.
* **`pinfo.csv`**: Patient and personal information tracking file.
* **`receiver.csv`**: Records of blood requests and recipient details.
* **`stock.csv`**: Live inventory management file tracking available blood units by group.

---

## Requirements

To run any of these projects, you need:
* Python 3.x installed on your computer.

## How to Run

1. Open the specific project folder you want to run on your computer.
2. Ensure all matching `.csv` files stay in that same folder with the script.
3. Open your terminal, command prompt, or IDE inside that folder.
4. Execute the script using the command:
   ```bash
   python "filename.py"
   ```
